no lugar certo.

Siga este mapa para configurar a instalação. A IPA é pública; o certificado e a senha ficam protegidos nos Secrets do GitHub.

01 · RELEASE

IPA assinada

GitHub → Releases → New release → anexe o arquivo `.ipa`.

02 · SECRET

Certificado `.p12`

GitHub → Settings → Secrets and variables → Actions → adicione o certificado em base64.

03 · SECRET

`.mobileprovision`

Adicione o perfil em base64 como Secret. A senha do `.p12` também fica somente nos Secrets.

Nunca envie aqui: senha, chave privada, arquivo `.p12` público ou certificado para download. Não use este fluxo para app de terceiros.
